Site Gsol Energia Solar - versão HTML e CSS

Site personalizado para a empresa de energia Solar Gsol
feito em HTML e CSS 

Formatação

Os estilos ficam em style.css e são aplicados às páginas HTML.
Para formatar os arquivos HTML e CSS:

  npm install
  npm run format

Para verificar se estão formatados corretamente:

  npm run format:check

No VS Code, instale a extensão Prettier recomendada pelo projeto. A formatação
automática está ativada ao salvar arquivos HTML e CSS.
